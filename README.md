# Business Studies Revision Room

A lightweight, static revision site for Class XII Business Studies chapters 1–8, 11 and 12.

- Condensed chapter notes, process maps, distinctions and case-study clue finders
- Instant-feedback MCQs plus 2-, 3- and 4-mark questions with revealable answer points
- Ten-question mixed practice sets and active-recall cards
- Progress saved locally in the browser

The notes and question styles are grounded in the chapter PDFs and school revision worksheets supplied for this study project. Consumer Commission limits in the notes follow the figures printed in that supplied chapter.

## Run locally

Open `dist/index.html` in a browser, or serve the `dist` folder with any static web server.

## Deploy

Pushing to `main` triggers the GitHub Actions workflow in `.github/workflows/pages.yml` and publishes the `dist` folder to GitHub Pages.
